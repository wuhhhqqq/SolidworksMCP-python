# 1.0.1 可靠性收口更新

本版本修正真实执行结果与面板展示不一致，以及旧接口返回示例成功的问题。

- 面板检查业务状态，失败、不支持、部分成功、待确认均不会显示完全成功；保留原错误和完整结果。
- 面板将连接操作串行化；健康检查发现实际断开后清除旧连接状态，下一次请求重新附加。
- 显式启动成功能恢复已打开的熔断器。
- drawing、analysis、automation 模块中缺少真实适配器的示例回退改为 `unsupported`。真实适配器分支保留。不要将本更新理解为所有旧功能均已补成 COM 实现。
- 修复未被独立收集的适配器注册测试。
- 发行版本与运行时版本统一为 1.0.1，客户端配置统一使用 stdio 启动脚本；源码包包含外部安装文件；安装脚本包含 UI 依赖并优先安装随包 wheel。
- Task Pane 补充 swpublished、WinForms、Drawing、动态调用构建引用，修正 DLL 路径；面板服务启动探测使用轻量健康接口。

验证：2026-10-15，当前源码选定离线回归 **339 passed**。测试覆盖面板/FastMCP 结果、适配器、旧工具契约、结构化工作流、DXF 导入及 CAXA DXF 规范化。wheel 与 sdist 构建成功，检查了面板资源和安装文件包含情况。未进行真实 SOLIDWORKS/CAXA 操作或异机安装，C# 插件未编译验收。

更新时先停止对应 MCP 客户端中的服务，解压完整新版并运行 `INSTALL-外部用户.ps1`，然后重新启动客户端。安装需要 Windows、64 位 Python 3.11+、本机 SOLIDWORKS 和可下载依赖的网络。ZIP 不包含 Python、SOLIDWORKS、许可证或全量离线依赖。

尚未收口：面板和独立 stdio 进程间的统一调度、启动超时后的防重复实例、快捷方式目标验证、复杂 Schema 图形表单、全工具 MCP 协议场景验收、CAXA 消费及异机安装验收。仍需按功能域逐项验证真实模型，不能把注册 255 个工具理解为 255 个真实场景全部通过。
